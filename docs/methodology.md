# Methodology

1. Requirement analysis: a command-line Library Management System was selected to cover the supplied Java syllabus.
2. OOP design: abstract classes provide common structure and concrete classes inherit from them.
3. Encapsulation: fields are private and accessed through methods.
4. Polymorphism: overridden methods demonstrate different object behaviours.
5. Exception handling: custom exceptions validate invalid operations.
6. Collections: ArrayList stores books and members.
7. File I/O: BufferedReader and BufferedWriter persist application data.
8. Multithreading: StatisticsTask extends Thread and calculates library statistics.
9. JDBC: SQLite is accessed using JDBC, prepared statements and result sets.
10. Testing: JUnit tests verify add, issue, return and exception workflows.
11. Execution: Maven provides reproducible command-line build and execution.
